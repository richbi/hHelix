# hHelix

This repository contains functions and a vignette accompanying preprint article "A self-similar helix as a metaphor for continuous time with nested periodicity" (Bischof 2025, https://www.biorxiv.org/content/10.1101/2025.03.06.640619v1). The file HierarchicalHelixVignette.html provides step-by-step explanations and code for creating and projecting timed data onto hierarchical helix structures (up TO 3rd order) for visUalizing timed information with nested periodicity as described in the article. The functions required to run the code in the vignette are in the "FUNCTIONS" folder.
