# hHelix


This repository contains functions and a vignette accompanying article "A self-similar helix as a metaphor for continuous time with nested1
periodicity" (Bischof 2025, DOI: XXXXXXXXX). The file HierarchicalHelixVignette.html provides step-by-step explanations and code for creating and projecting timed data onto hierarchical helix structures (up 3rd order) for visalizing timed information with nested periodicity as described in the article.
The functions required to run the code in the vignete are in the "FUNCTIONS" folder.
